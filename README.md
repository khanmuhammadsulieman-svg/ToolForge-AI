# ToolForge AI

A premium browser-first toolkit for images, video, PDFs and document scanning.

## Included tools
- Image Compressor
- Video Compressor
- PDF Compressor / optimizer
- PDF Merger
- AI Document Scanner with 10 filters
- Image Resizer
- Image Converter
- PDF → Images
- Images → PDF
- PDF Splitter

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

Deploy the project to Vercel or Cloudflare Pages as a Vite app. No database is required for the current version.


## AI Scanner

The document scanner uses browser-only smart detection and enhancement. No OpenAI API key or backend endpoint is required.
